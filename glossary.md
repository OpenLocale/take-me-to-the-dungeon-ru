# Глоссарий русификатора

- **Una → Юна**: Юны, Юне, Юну, Юной.
- **Noa → Ноа**: женское имя, не склоняется.
- **Mona → Мона**, **Pamela → Памела**, **Bluey → Блуи**, **Pinky → Пинки**.
- **Vampire Queen → Королева вампиров**, **Succubus Queen → Королева суккубов**.
- **Health / HP → здоровье**, **Armor → броня**, **Hand → карты в руке**, **Crystal → кристаллы**.
- **Rune → руна / руны**, **Aura / Halo → аура**, **Charge → заряд**.
- **Charge Up (эффект) → Зар.**: краткое неизменяемое обозначение для счётчика (`1 Зар.`, `6 Зар.`); в пояснениях — «заряды».
- **Logii → логия**: название вымышленного животного, не обычного кабана; `Young Logii` → `Молодая логия`, `Logiilii` → `Логилий`. Согласовано с упоминаниями мяса логии в сюжете.
- Свойства карт: **сила**, **скорость**, **магия**, **без свойства**.
- **Hot Spring → горячий источник**; краткая подпись круглого значка — **Источник** (`ui.dungeon_scene.hot_sprint`). В описаниях и обучении полное название сохраняется.
- Раздел галереи: **Воспоминания**; вкладки: **Иллюстрации**, **Анимации**, **Сцены**.
- Прямые эротические обозначения сохраняются без эвфемизации и цензуры, если они прямые в исходнике.

## Принятые решения

Места, которые уже проверялись и сознательно оставлены. Менять только при новом конкретном доказательстве дефекта.

- **«Молодая логия»** (`monster.304.name`): в сюжете животное и его мясо названы `logii`, а не `boar`; женский род задаёт русское название, а не пол спрайта.
- **«Раз уж для танго нужны двое…»** (`Plot80404.0#8.message`): метафора есть в английском исходнике; смысл и шутливый обход темы сохранены.
- **`Plot81001.調戲潘蜜拉#20.message`**: английский исходник отрицателен и противоречит сцене; CN/TW/KO говорят, что ещё один человек сделает картину полнее. Оставлен положительный смысл.
- **Короткие реплики `Plot9080401.0#4`, `Plot9100401.0#107`, `Plot9090401.0#74`**: смысл зависит от отображаемого говорящего; без замечания из игры не менять.
- **«Осталось ОД»** (`ui.dungeon_shop.remain_action_time`): отличие начертания — штатный полужирный стиль поля, не другой шрифт; одобрено.
- **Превью «ЗОЛОТО I» / «РУНЫ I»**: разная ширина и положение подписей заложены в самих изображениях и длине русских слов, панель не смещается.
- **Описания «Сосредоточение» и «Избыток»**: сверены с кодом игры, претензии к ним отозваны.
- **Управление A/D/Space**: исходное управление игры; переводятся только подсказки, привязки клавиш не меняются.

# AGENTS.md

## Назначение

Репозиторий содержит неофициальный русский перевод Take Me To The Dungeon!! и инструменты, реально использованные для сборки assets-патча.

## Основные правила

- По прямому запросу пользователя2026-10-13 подготовить и опубликовать v0.9.0 из проверенного пакета до последних трёх исправлений. Эти исправления и пользовательский русский логотип главного меню относятся к v0.9.1: собрать, проверить, установить при закрытой игре, синхронизировать ветку, выполнить merge в main и выпустить релиз. Нумерация v0.9.0/v0.9.1 подтверждена пользователем. Основной приватный корпус и прежний release2026-10-08 сохранять; чужие изменения Steam-гайда не трогать.
- Прямое правило пользователя для повторной вычитки: не переписывать хорошо написанный текст. Менять только при конкретном доказуемом дефекте смысла, грамматики, управления, машинной кальке или потерянном голосе/интонации. Для каждой правки иметь краткое основание; вкусовой синоним не основание.

- Не добавлять `.exe`, `.ps1`, `.bat` или автоматический установщик без отдельного решения проекта.
- Основной пользовательский способ установки — ручное копирование файлов из Release ZIP.

- Сохранять ключи, порядок записей, placeholders, rich-text tags и терминологию перевода.

- Те же требования к формальному и краткому стилю применять к пользовательским README.md и инструкции релиза README.txt. Не включать внутренние процессы, пояснения о повторной вычитке и пометку о взрослом контенте без цензуры. Версия, совместимость, состав установки и действия пользователя должны оставаться точными.
- Не добавлять в руководство пометку «Взрослый контент — без цензуры», по решению пользователя от 2026-10-13.
- Весь текст руководства писать формально и лаконично. Не включать сведения о вычитке, повторных проходах, постредактуре, внутренних этапах работы и наследовании исправлений между версиями. Указывать содержание перевода, совместимость, точные действия установки и краткие результаты изменений для игрока.
- Changelog в руководстве писать профессионально и кратко: описывать реальные изменения относительно предыдущего публичного выпуска и результат для игрока. Не переносить внутренние детали разработки, промежуточные правки, подгонку интервалов и плашек, работу агентов или отладочные сведения. Мелкие визуальные правки объединять в понятный пункт об улучшении отображения интерфейса; установочные требования и реальные ограничения указывать точно.
- Игровые скриншоты добавлять в разделы руководства Steam только после полного релиза перевода, по решению пользователя от 2026-10-13. До этого не загружать их и не вставлять заглушки под изображения.
- По решению пользователя от 2026-10-13 не включать в руководство Steam блок «v1.7 — 15 августа 2026», описание первого публичного выпуска OpenLocale и пояснение старой нумерации. Не восстанавливать этот блок при обновлении руководства, смене версии или переносе changelog из репозитория без нового прямого запроса пользователя.
- Правило относится к руководству Steam и его локальным шаблонам. Исторические записи в `CHANGELOG.md` и `HISTORY.md` сохранять; при подготовке текста руководства пропускать этот блок.

## Структура

- `README.md` — пользовательская установка и совместимость.
- `release/README.txt` — версия инструкции, включаемая в Release ZIP; хранится в Git отдельно от игровых файлов.
- `STEAM_GUIDE.txt` — готовый BBCode-текст руководства для Steam.
- `.github/ISSUE_TEMPLATE/` — формы ошибок перевода и технических проблем.
- `tools/localize.py` — extraction, integrity check, TextAsset write-back и verify.
- `tools/font-importer/` — перенос статического TMP fallback в `resources.assets`.
- `tools/unity-font-builder/` — минимальные исходники Unity/TMP-выпечки с открытым `Noto Sans Regular`; извлечённый из игры `CJKtc.ttf` не публикуется.

Рабочий `translation.json`, исходные assets и результаты сборки хранятся вне Git. Публичный репозиторий намеренно не является полным дампом сценария игры.

## Проверка и сборка

Python-зависимость:

```powershell
python -m pip install -r tools/requirements.txt
```

Проверка корпуса:

```powershell
python tools/localize.py check --work <translation.json>
```

Сборка текстового assets из оригинального файла:

```powershell
python tools/localize.py build --game-asset <resources.assets.ru-original> --work <translation.json> --output <build/resources.assets>
```

Проверка собранного файла:

```powershell
python tools/localize.py verify --game-asset <resources.assets.ru-original> --work <translation.json> --built-asset <build/resources.assets>
```

Статический TMP fallback выпекается из включённого `NotoSans-Regular.ttf` в Unity `2022.3.62f3` с TextMeshPro `3.0.6`, после чего импортируется `tools/font-importer`. Готовый AssetBundle собирается локально и не входит в Git.

Release формируется вручную: инструкция `release/README.txt` и оба итоговых файла `Take Me To The Dungeon!!_Data/resources.assets` и `Take Me To The Dungeon!!_Data/il2cpp_data/Metadata/global-metadata.dat` упаковываются в `TakeMeToTheDungeon-RU.zip`. Хэши в текущем рабочем процессе не вычисляются.

## Правила этой игры

- Русский текст физически заменяет English locale; в игре пользователь выбирает English.
- Поддерживаемая сборка игры — Steam build `25319640`; пользовательский скриншот меню показывает1.7.7-release-steam. Выпуски0.9.0/0.9.1 разделены по запросу пользователя; предыдущие предварительные статусы больше не запрещают их публикацию. Актуальные данные и следующая точка — `NEXT_WORK.md`; не смешивать установленную версию с архивом другого выпуска.
- Основной TMP font asset остаётся `CJKtc SDF`; кириллица подключается статическим fallback.
- Font importer содержит path ID, специфичные для этой сборки игры. Не применять его к другой версии без повторной проверки структуры assets.
- Финальный патч всегда собирать из сохранённого оригинального `resources.assets`, а не из ранее модифицированной версии.

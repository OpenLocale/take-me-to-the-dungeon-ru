# AGENTS.md

## Назначение

Репозиторий содержит неофициальный русский перевод Take Me To The Dungeon!! и инструменты, которыми собирается патч игровых файлов. Рабочий корпус, исходные assets и результаты сборки хранятся вне Git: публичный репозиторий намеренно не является дампом сценария игры.

## Ветки и выпуски

- `feature/<тема>` — новые возможности и эксперименты; `fix/<тема>` — исправления; `chore/<тема>` — обслуживание; `docs/<тема>` — документация. Не разрабатывать прямо в main. Независимую возможность держать отдельно от исправлений.
- Тематические ветки объединять в `release/next` (или `release/<версия>`). Пользователь проверяет один общий пакет, а не каждую ветку. Новые ошибки кандидата исправлять в fix-ветке и включать в общий пакет.
- Полная сборка и `verify` — один раз после объединения пакета. Без изменения игровых исходников сборку не повторять.
- Для кандидата фиксировать коммит, состав веток и приватный снимок `translation.json`: корпус и PNG не версионируются Git.
- Отправка и слияние служебных веток (chore/docs/fix) разрешены. В main переносить игровой кандидат только после явного одобрения пользователем; изменения после одобрения не подмешивать без новой проверки. Публичный выпуск, удаление или переименование тегов, создание репозиториев и переписывание истории — только по прямому запросу.
- Не переименовывать существующие ветки и не сбрасывать чужие изменения автоматически.

## Перевод

- Не переписывать хорошо написанный текст. Менять только при конкретном доказуемом дефекте смысла, грамматики, управления, машинной кальки или потерянного голоса и интонации. Для каждой правки нужно краткое основание; вкусовой синоним основанием не является.
- Сохранять ключи, порядок записей, placeholders, rich-text tags и терминологию (`glossary.md`). Решения из раздела «Принятые решения» глоссария не пересматривать без нового доказательства.
- Не добавлять новые привязки клавиш, способы выбора или розыгрыша карт и другие изменения управления. A/D/Space — исходное управление игры: подсказки переводятся, input maps и GameAssembly не патчатся.
- Замечания из игровой проверки записывать в `QA_CHECKLIST.md` или в Issue и исправлять последовательно. Фактические изменения новой версии собирать в `CHANGELOG.md` после перепроверки.

## Файлы и распространение

- Не коммитить Release ZIP, собранные `resources.assets` и `global-metadata.dat`, корпус, PNG и файлы анимаций.
- Не добавлять `.exe`, `.ps1`, `.bat` или автоматический установщик без отдельного решения проекта. Основной способ установки — ручное копирование файлов из Release ZIP.
- В Git не публиковать извлечённые из игры шрифты, исходные assets и сценарий. Открытый `Noto Sans` с лицензией входит в font-builder.
- По решению пользователя от 2026-11-21 Release ZIP распространяет полные модифицированные `resources.assets` и `global-metadata.dat`; состав и принятый риск описаны в `RIGHTS.md`. Состав архива не расширять: только `README.txt` и эти два файла. Delta-патч и другие модели распространения не вводить без нового решения пользователя.
- Не изменять бинарные игровые файлы без понимания `tools/localize.py`, `tools/localize_ui.py` и шрифтового pipeline. Перед изменением структуры изучить существующий pipeline.

## Публичные тексты

- Каждый Release указывает версию перевода и поддерживаемую сборку игры. При выпуске одновременно обновлять `README.md`, `release/README.txt`, Release notes и `STEAM_GUIDE.txt`.
- Release notes и changelog описывают реальные изменения относительно последней опубликованной версии и результат для игрока. Не переносить туда чат, статусы проверки, внутренние номера замечаний, работу агентов, детали сборки и исправления промежуточных локальных вариантов. Мелкие визуальные правки объединять в один пункт. Установочные требования и известные ограничения указывать точно.
- README, README.txt и руководство Steam писать формально и кратко: содержание перевода, совместимость, точные действия установки и удаления. Не упоминать вычитку, повторные проходы и внутренние этапы работы.

## Руководство Steam

- Живое руководство обновляет отдельный агент; не редактировать его параллельно.
- Не добавлять пометку «Взрослый контент — без цензуры».
- Скриншоты добавлять только после полного выпуска перевода; до этого не вставлять ни изображения, ни заглушки.
- Не включать блок «v1.7 — 15 августа 2026», описание первого публичного выпуска OpenLocale и пояснение старой нумерации без нового прямого запроса. Исторические записи в `CHANGELOG.md` и `HISTORY.md` при этом сохраняются.

## Структура

- `README.md` — установка и совместимость для игроков.
- `release/README.txt` — инструкция внутри Release ZIP.
- `STEAM_GUIDE.txt` — BBCode-текст руководства Steam.
- `CHANGELOG.md`, `HISTORY.md`, `RIGHTS.md` — история изменений, происхождение проекта, правовой статус.
- `glossary.md` — терминология и принятые решения по переводу.
- `QA_CHECKLIST.md` — чек-лист игровой проверки кандидата.
- `.github/ISSUE_TEMPLATE/` — формы ошибок перевода и технических проблем.
- `tools/` — pipeline сборки; описание и команды — `tools/README.md`.

## Проверка и сборка

Окружение — Python 3.12 (`.python-version`) с точным набором `tools/requirements.txt`; другие версии Python не поддерживаются. Полная последовательность команд — `tools/README.md`.

- Корпус: `localize.py check`.
- `resources.assets`: `localize.py build` из оригинального файла Steam → `localize.py font-fallback` с донором из последнего выпуска → `localize.py verify`.
- Метаданные: `localize_ui.py patch-runtime-metadata` и `verify-runtime-metadata` из чистого `global-metadata.dat` Steam.
- Воспроизводимость: `localize.py compare` с последним выпуском; без изменений исходников результат обязан совпасть с выпуском.
- Перевыпечка шрифта в Unity и `tools/font-importer` нужны только при доказанной проблеме с глифами.
- Release формируется вручную: `release/README.txt` и два игровых файла упаковываются в `TakeMeToTheDungeon-RU.zip`. Хэши не вычисляются.

## Правила этой игры

- Русский текст физически заменяет English locale; в игре выбирается English.
- Поддерживаемая сборка — Steam build `25319640` (в меню игры `1.7.7-release-steam`). Не смешивать установленную версию с архивом другого выпуска.
- Основной TMP font asset остаётся `CJKtc SDF`; кириллица подключается статическим fallback `CJKtc RU SDF` (Noto Sans Regular).
- Смещения и path ID в инструментах специфичны для этой сборки. Не применять их к другой версии без повторной проверки структуры assets.
- Финальный патч всегда собирать из оригинальных файлов Steam, а не из ранее модифицированных.
